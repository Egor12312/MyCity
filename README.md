Приложение "My City: Кемерово"

Описание проекта
Разработано Android-приложение на Jetpack Compose, представляющее собой путеводитель по интересным местам города Кемерово. Приложение содержит 3 категории мест (Рестораны, Кафе, Парки) по 3 места в каждой.

Выполненные требования:
Многоэкранность и навигация: Реализована навигация между категориями с помощью Jetpack Navigation Compose (NavHost, rememberNavController). Добавлены маршруты в enum class Routes.

Разделение слоев (Архитектура):

Model/Data: Данные вынесены в Place и PlacesRepository.

UI: Интерфейс реализован в компонуемых функциях.

ViewModel: Логика работы с данными инкапсулирована в MyCityViewModel.

UDF (Однонаправленный поток данных):

Состояние экрана хранится в MyCityUiState и передается через StateFlow.

UI подписывается на изменения через collectAsStateWithLifecycle().

События от пользователя (выбор категории, выбор места) отправляются в ViewModel через вызовы функций.

Адаптивный дизайн:

Используется WindowSizeClass для определения ширины экрана.

Применен паттерн List-Detail:

На смартфонах (Compact) показывается либо список, либо детали (с кнопкой "Назад").

На планшетах (Medium/Expanded) экран делится на две колонки: список слева, детали справа.

Используется NavigationSuiteScaffold из Material 3 Adaptive для автоматического переключения между нижней панелью навигации (на телефоне) и боковой панелью (на планшете).

Ресурсы: Все текстовые данные вынесены в strings.xml, изображения добавлены в папку res/drawable.
